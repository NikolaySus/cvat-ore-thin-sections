# Доразметка Рудных Шлифов В CVAT

Плагин для self-hosted CVAT Community и отдельный FastAPI-сервис автоматизированной доразметки. Алгоритмы перенесены из проекта `ezulhreasqkpvbct/nornik_app`: цветовая кластеризация, коррекция освещения и теней, уточнение границ, экспертная коррекция областей талька. Нейросетевые веса и GPU для этого сервиса не требуются.

В редакторе CVAT команда **Menu → Доразметка шлифа** открывает рабочую панель. Можно настроить алгоритм, импортировать экспертный эскиз или нарисовать контуры, соединить их концы прямой/кривой/маршрутом по краю изображения, изменить форму кривой и выбрать внутреннюю либо внешнюю область. Результат сначала показывается в предпросмотре, затем добавляется как редактируемые маски CVAT.

| Класс | Цвет |
| --- | --- |
| Силикатная/оксидная матрица | Жёлтый |
| Сульфидные фазы | Красный |
| Тальк | Синий |
| Дефекты | Бордовый |

## Локальный Запуск

Требуются Docker с Compose версии 2.24.4 или новее, Git и доступ к Docker Hub/GitHub. Версия CVAT закреплена: **v2.77.0**, commit `7dac20c766d7d4297fdf67589436387ab26f7411`.

```bash
bash scripts/prepare.sh
bash scripts/compose.sh build ore_service cvat_ui
bash scripts/compose.sh up -d
bash scripts/create-user.sh
```

Адрес: **http://localhost:8080**. Локальная тестовая учётная запись: `ore`, пароль `ore-local-demo`. Скрипт создания пользователя задаёт этот пароль повторно; используйте его только для тестового стенда.

При первом запуске CVAT несколько минут выполняет миграции. Состояние можно проверить:

```bash
curl http://localhost:8080/api/server/health/?format=json
bash scripts/compose.sh logs --tail 50 cvat_server ore_service
```

Контейнеры и тома имеют отдельный префикс `ore-cvat`, сеть — `172.30.90.0/24`. Порт опубликован только на localhost. Существующие сервисы проекта не затрагиваются. Для этой машины порог проверки заполнения диска CVAT установлен в 97%; сам алгоритм не освобождает и не удаляет данные.

## Работа С Разметкой

Создайте задачу с изображениями и четырьмя метками типа **mask**. Удобные названия: `Матрица`, `Сульфидные фазы`, `Тальк`, `Дефекты`. При других названиях выберите соответствия в панели «Метки CVAT».

Чтобы плагин мог заменять свои предыдущие маски после повторного открытия задания, добавьте каждой метке неизменяемый текстовый атрибут `ore_run`, начальное значение — пустая строка. Тестовый генератор создаёт такие метки автоматически. Добавление масок работает и без этого атрибута; замена требует его наличия.

1. Откройте задание и команду **Menu → Доразметка шлифа**.
2. При необходимости импортируйте эскиз через раздел «Экспертный эскиз». Размер файла должен совпадать с исходным кадром; синие линии извлекаются автоматически.
3. Контуры автоматически обновляются после завершения действия и паузы 700 мс. Инструмент соединения позволяет последовательно выбрать два конца, затем изменить маршрут и положение управляющих точек. Новые линии рисуются инструментом карандаша.
4. Ластик «Удалить контур» подсвечивает и удаляет всю связную группу линий и соединений; отдельные, в том числе вложенные, контуры остаются. Удаление можно отменить кнопкой Undo в панели. Выберите область и включите «Коррекция по эскизу», если она нужна.
5. На новом кадре эксперт сохраняет незавершённые наметки кнопкой «Сохранить черновик» или передаёт их на доработку. Замыкание на этом этапе не требуется. При передаче сохраняется отдельный неизменяемый экспертный исходник.
6. На этапе «Доработка» замкните все контуры, нажмите «Рассчитать маски», затем «Передать на проверку». Предпросмотр показывает наложение и доли классов; открытые линии и устаревшие результаты блокируют передачу.
7. Эксперт принимает комплект контуров и масок либо возвращает его с замечанием. «Исправить самому» возвращает кадр на доработку и открывает карандаш. После правок требуется новый расчёт и повторная проверка.
8. После принятия «Добавить маски» сохраняет существующие объекты. «Заменить предыдущие» удаляет только маски с атрибутом плагина после подтверждения, включая их ручные изменения.
9. Закройте панель, при необходимости исправьте маски средствами CVAT и нажмите штатную **Save**. Добавление поддерживает **Undo/Redo**; при замене удаления предыдущих объектов также входят в историю CVAT.

Этапы кадра: **Наметки → Доработка → На проверке → Принято**. Режим выбирается автоматически по этапу; ограничения по роли пользователя пока нет. Переходы сохраняют автора и время. Навигация к следующему кадру остаётся штатной в CVAT. Экспортированные настройки JSON не содержат этапов и решений эксперта.

Экран проверки открывается без инструментов редактирования. На одном полотне автоматически чередуются оригинал с наметками, чистовые контуры, маски с контурами: по одной секунде с переходами 0,3 секунды. Цикл запускается после загрузки слоёв, не отправляет запросы и не пересчитывает данные. Доступны пауза, неподвижные состояния, масштабирование и перемещение. При системном предпочтении уменьшенной анимации сразу показаны маски с контурами; скрытая вкладка приостанавливает цикл. Сначала доступны только решения «Принять» и «Отклонить». После отклонения цикл приостанавливается, появляются поле замечания и варианты возврата разметчику или самостоятельной правки; отмена этого решения не меняет этап кадра.

Проверка относится к сохранённому комплекту конкретной версии, а не к меняющемуся черновику. Принятую версию нельзя редактировать без явного возврата на доработку. Уже применённые объекты CVAT при возврате не удаляются. Для старых кадров с эскизом устанавливается этап «Доработка», для пустых — «Наметки»; экспертный оригинал задним числом не создаётся.

В режиме «Результат» переключатель «Показать эскиз» накладывает обработанные контуры и соединения поверх маски. Если геометрия отсутствует или устарела, она сначала пересчитывается. Исходные карандашные штрихи и маркеры редактирования в этом режиме не показываются; прозрачность маски регулируется отдельно.

Настройки и эскиз сохраняются независимо для каждого задания и кадра. Настройки можно импортировать/экспортировать в JSON, эскиз — скачать как PNG. Экспорт датасета выполняется штатными средствами CVAT. Маски создаются по одному объекту на непустой класс, включая несвязные области.

«Автообновление контуров» включено при открытии панели. Если его выключить, появляется кнопка «Обновить контуры». Фоновый пересчёт не блокирует карандаш и перемещение изображения, не сохраняет настройки и не рассчитывает маски. Ластик, соединение концов и экспорт доступны для актуальной геометрии. Старые контуры сохраняются до готовности нового снимка; устаревшие ответы не применяются. При ошибке автоматический бесконечный повтор не выполняется: измените эскиз либо выключите и включите автообновление.

Соединение после выбора двух концов является пунктирным черновиком. Галочка рядом с центральной ручкой подтверждает его, крестик отменяет. До подтверждения черновик не замыкает контур, не участвует в коррекции, экспорте и удалении связных групп ластиком. Это относится ко всем маршрутам: прямой, кривой и пути по краю. При редактировании подтверждённого соединения прежняя версия действует до нажатия галочки; отмена оставляет её неизменной. Перетаскивание черновика не запускает геометрический пересчёт. Черновики не сохраняются в настройках и отбрасываются при закрытии панели.

## Устройство И API

`plugin/` содержит React/TypeScript-плагин, который собирается вместе с интерфейсом CVAT через `CLIENT_PLUGINS`. `server/` содержит самостоятельное вычислительное ядро и API. `vendor/cvat` загружается скриптом подготовки и игнорируется Git; копии исходного репозитория сайта для запуска не нужны.

Браузер обращается к `/ore/api/` на том же адресе, что и CVAT. Сервис передаёт текущую сессию CVAT при проверке доступа к заданию и загрузке оригинального кадра. Применение аннотаций выполняет интерфейс через штатное ядро CVAT, учитывая его права и механизм сохранения.

| Запрос | Назначение |
| --- | --- |
| `GET /ore/api/health` | Состояние, настройки по умолчанию и диапазоны |
| `GET/PUT /ore/api/frames/{job}/{frame}` | Настройки и ревизия кадра |
| `POST /ore/api/frames/{job}/{frame}/transition` | Переход: `revision`, `action` (`handoff`, `submit`, `accept`, `reject`, `reopen`), `note`, `result_id` для передачи масок |
| `GET /ore/api/frames/{job}/{frame}/expert.png` | Неизменяемые экспертные наметки после передачи |
| `GET /ore/api/frames/{job}/{frame}/image` | Изображение для просмотра |
| `POST/DELETE /ore/api/frames/{job}/{frame}/sketch?revision=N` | Импорт эскиза multipart `file` / очистка |
| `GET /ore/api/frames/{job}/{frame}/sketch` | Исходный импортированный эскиз |
| `POST /ore/api/frames/{job}/{frame}/preview` | Несохранённый снимок: `revision`, `session`, `generation`, `state` |
| `GET/DELETE /ore/api/previews/{id}` | Статус и результат / отмена предпросмотра |
| `POST /ore/api/frames/{job}/{frame}/jobs?revision=N&kind=segmentation` | Расчёт масок; `kind=geometry` — контуры |
| `GET/DELETE /ore/api/jobs/{id}` | Состояние/отмена расчёта |
| `GET /ore/api/jobs/{id}/result` | Геометрия либо маски RLE CVAT и статистика |
| `GET /ore/api/jobs/{id}/mask.png` | Цветовая маска предпросмотра |
| `GET /ore/api/jobs/{id}/overlay.png` | Наложение на исходное изображение |

Настройки записываются с проверкой ревизии: конфликт параллельных изменений возвращает HTTP 409. Устаревший результат нельзя применить. Один расчёт выполняется в отдельном процессе, ещё восемь могут ожидать в очереди; переполнение возвращает HTTP 429. Таймаут по умолчанию — 900 секунд. Отмена завершает вычислительный процесс. Результаты и статусы сохраняются на диске; прерванный перезапуском расчёт нужно запустить заново.

Ответ кадра дополнен `workflow`: этап, экспертный исходник, комплект проверки, замечание и журнал переходов. Этапы используют общую ревизию с настройками. Сервер проверяет переходы, замыкание контуров и соответствие расчёта кадру, настройкам и импортированному эскизу. Файл импорта для вычислительного задания копируется в его каталог, поэтому последующая загрузка другого эскиза не меняет уже запущенный расчёт. Снимки проверки и результатов сохраняются после перезапуска сервиса.

Предпросмотр геометрии использует отдельный прогретый CPU-процесс, независимо от очереди масок. Для одной панели хранится максимум один ожидающий снимок; новые изменения заменяют его. Ограничение ожидающей очереди — 32 панели. Завершённые предпросмотры хранятся временно: очистка при новых заданиях, TTL 5 минут, целевой предел 64 записей. После перезапуска временные задания недоступны и панель запрашивает геометрию заново.

Штрихи хранятся как `{id, points}`, а удалённые компоненты импорта — в `deletedImportedComponents`. Старые массивы точек и JSON без этого поля принимаются и нормализуются автоматически. Исходный импорт не изменяется при работе ластиком, поэтому Undo восстанавливает удалённые линии.

Параметры сервиса: `CVAT_URL`, `DATA_DIR`, `JOB_TIMEOUT`, `MAX_IMAGE_PIXELS`. Данные хранятся в `data/ore`: SQLite с настройками, исходные кадры, эскизы и результаты. Этот каталог игнорируется Git. Автоматическая очистка сохранённых результатов масок пока не реализована.

По умолчанию сегментация работает с длинной стороной 1300 пикселей, как прежняя доразметка. Размер можно выбирать от 128 до 4096. Маски масштабируются в координаты оригинала ближайшим соседом; RLE строится построчно. Это не добавляет деталей, потерянных при уменьшении. Обработка экспертных контуров использует исходные координаты и на больших панорамах может требовать значительного объёма RAM. Исходный кадр CVAT при коррекции не обрезается.

## Проверки

```bash
python3 -m venv .venv
.venv/bin/pip install -r server/requirements.txt pytest
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 .venv/bin/pytest -q
.venv/bin/python scripts/seed.py --image /path/to/thin-section.jpg
.venv/bin/python scripts/check.py
```

Без `--image` генератор создаёт синтетический тестовый кадр. Он создаёт новую задачу с двумя изображениями, сохраняет адрес задания в `data/fixture.json` и эскиз с двумя разрывами в `data/fixture-sketch.png`. Проверочный скрипт работает со вторым кадром: проверяет авторизацию, конфликты ревизий, расчёт, отмену ожидающего задания и получение маски.

Локальная браузерная проверка проводится в настоящем CVAT через Playwright. Отчёт — `LOCAL_TEST_REPORT.md`, снимки интерфейса — в игнорируемом каталоге `output/playwright`.

## Подключение К Другому Self-Hosted CVAT

Плагин требует сборки интерфейса CVAT. Для CVAT v2.77.0 скопируйте `plugin` в `cvat-ui/plugins/ore`, добавьте `plugins/ore` к `CLIENT_PLUGINS` при сборке `Dockerfile.ui`, запустите образ сервиса и направьте `/ore/` на его порт 8090 через общий reverse proxy. В `CVAT_URL` задайте внутренний адрес сервера CVAT; имя хоста должно быть корректным DNS-именем, например `cvat-server`.

Используйте отдельный постоянный том для `DATA_DIR` и включите его в резервное копирование вместе с данными CVAT. Публичное развёртывание в этой версии не выполнялось. Совместимость с другими версиями CVAT требует повторной сборки и проверки API плагинов.
